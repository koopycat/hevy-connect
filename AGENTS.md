# hevy-axi agent guide

`hevy-axi` is an agent-ergonomic TypeScript CLI over all 22 documented Hevy Public API operations. Keep the interface safe for unattended reads and deliberately gated mutations.

## Commands

```bash
just install          # locked dependency install
just run --help       # run the TypeScript entrypoint
just build            # regenerate dist/
just api-types        # regenerate src/generated/hevy-api.ts from the OpenAPI capture
just api-sync         # refresh the capture from the live docs (network), then regenerate
just test             # unit and integration tests
just check            # lint, format check, types, tests, build
just link             # build and link hevy-axi globally with pnpm
```

## Invariants

- Never commit or print API keys, real Hevy IDs, or personal health/workout data; `.env` and credential files remain local and mode `0600` on POSIX.
- Do not add response, health-data, or synchronization caches. Commands read live state and redact credentials from failures.
- Treat the Hevy API as unstable: preserve tolerant response-envelope decoding and re-check the official contract before release; see `docs/hevy-api-analysis.md`.
- `docs/hevy-openapi.json` is the verbatim official OpenAPI document embedded in `https://api.hevyapp.com/docs/swagger-ui-init.js`, captured 2026-10-07. Never edit it by hand; replace it only with a fresh verbatim capture (`just api-sync` does this and fails before writing if the repairs cannot handle the new spec). After a sync that changes content, update the SHA and capture date here and in `docs/hevy-api-analysis.md`, and the analysis wherever the contract changed. `just api-sync` is not part of `just check` or `just build` because it needs the network. The weekly workflow `.github/workflows/api-sync.yml` has two jobs. `refresh` runs `scripts/api-sync-refresh.sh` on the homelab runners (`runs-on: [self-hosted, linux, x64, homelab]`, which needs the repository topic `homelab-runner`), with no write credential, and uploads plain files. `publish` runs `scripts/api-sync-publish.sh` with the write token, from the default branch only. It builds on `automated/hevy-api-sync` (never force-pushes), opens or updates a PR from that branch, and closes the PR without deleting the branch when the difference is gone. A failing check opens the PR as a draft. Opening the PR needs the repository setting that lets Actions create pull requests.
- Keep POST and PUT free of automatic retries. Mutations require explicit `--confirm` or offline `--dry-run`; measurement update must retain its read-merge-write protection. `exercise create` checks every template title on `--confirm` (never on `--dry-run`) and refuses a match unless `--allow-duplicate` is given; if that scan cannot complete, nothing is created.
- `dist/` is generated by `just build`; change `src/`, never generated output by hand.
- `src/generated/hevy-api.ts` is generated by `just api-types` from the verbatim capture. Repairs for the capture's malformed OpenAPI 3.0 live only in `scripts/generate-api-types.ts`, which asserts each repair target so an upstream change fails loudly. `pnpm check` fails when the generated file is stale.
- Dependency updates come from Renovate through the shared preset `github>koopycat/renovate-config` (`renovate.json`): one weekly PR for minor and patch updates, GitHub Actions in their own PR pinned to commit SHAs with a version comment (keep the version as the last text of the comment), majors only when ticked on the Dependency Dashboard. Do not add Dependabot version or security updates; the two bots would open the same PR. `renovate.json` caps `typescript` below 6.1.0 because `typescript-eslint` does not support TypeScript 7 yet; remove that cap when it does.
- Node: CI and the sync workflow run the active LTS release (`node-version: lts/*`: 24 now, 26 from 2026-10-28). `engines.node` in `package.json` is the supported floor, set by hand to the oldest LTS in use (`>=24`); Renovate is told not to rewrite it. Raise it only when dropping an LTS line.
- Keep `PROJECT.md` outcome and unchecked experiment decision current when a change alters the tested hypothesis or lifecycle.
